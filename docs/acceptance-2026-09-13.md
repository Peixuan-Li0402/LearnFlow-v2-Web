# 2026-09-13 验收记录

## 结论

LearnFlow v2.0.0 发布副本已完成本轮功能验收，公开仓库不包含 Skill、课程数据库、用户课件或任何密钥。验收重点是学生实际使用时的题目呈现、讲解交互、数学符号、课程空间和知识图谱。

## 自动化检查

公开发布副本的 `npm test` 通过 55 项：8 项构建产物检查和 47 项 TypeScript 回归测试；`npm run typecheck` 通过。私有原始环境额外包含本地 Skill 相关检查，`npm test` 通过 57 项。构建过程只有 Vite 的大 chunk 提示，没有编译错误。

回归覆盖了：模型失败重试与备用模型、非法 JSON、空数组和截断响应、课程项目与独立作业隔离、参考资料检索、PDF 分批视觉解析、SSE 协议、会话交接、知识图谱导入导出、公式定界符、OCR 英文数学词、上下极限、集合运算符和历史乱码修复。

## 浏览器验收

在本地学习台中使用现有概率论课程项目进行回归：

- 第 1 题验证交集事件域：题目和标准答案清楚，`Ω、σ` 等符号可见，无裸 LaTeX。
- 第 2 题最小事件域元素个数：发现旧缓存曾把 `Ω` 污染成 `θ`，现已强制丢弃污染蓝图并重新解题；刷新后主答案只保留核验后的 `2^n` 推导，旧污染 assistant 消息不再回流。
- 第 3 题证明概率连续性定理：先询问前置知识，学生回答后针对 `liminf/limsup` 误区继续讲解，并再次提出当前步骤的检查问题；未提前推进到下一步。

跨题切换后题目、答案和讲解没有串题。课程空间可以打开课程资料、知识学习和复习图谱；图谱的章节树、依赖图和搜索入口可用，节点点击后视图不会自动重置。刷新学习页可以恢复已生成的课程讲解。浏览器控制台 error/warn 为空。

## 关键修复

模型先生成并复核隐藏解题蓝图，再基于蓝图讲解；强模型超时会进入针对当前回答的安全兜底，不生成伪答案，也不会白屏。直接查看答案会清除当前题目的旧答案块和历史污染 assistant 消息，然后以新蓝图替换，避免错误结果继续显示。

所有进入页面的模型文本都会经过数学文本修复和渲染校验，统一处理双重转义、`cases`、`frac`、`limsup/liminf`、`bigcup/bigcap`、`forall`、英文 OCR 读法及控制字符。课程图谱和知识路径标签也经过同一套符号清理。

## 学生视角体验

第一轮先看到题目目标、方法和前置知识摸底；第二轮学生反馈“会用定义但不理解上下极限”后，agent 先判断回答中的正确部分，再只解释当前误区；第三轮继续请求时，系统按已完成检查点推进。页面左侧标准答案、中央讲解和右侧知识助手保持同一题目上下文，切题后旧消息不会串入。

## 未纳入本地自动化的边界

Chrome 文件选择器曾受浏览器扩展权限限制，因此自动化脚本只能验证上传接口和页面上传状态，不能把该权限限制归咎于应用本身。正式环境仍需在目标部署环境配置模型服务、存储和访问控制；本仓库不宣称已完成公网部署或安全审计。依赖审计仍有上游依赖告警，属于后续单独的安全维护项。

本记录证明的是已覆盖场景的功能稳定性，不对任意课程、任意扫描质量和所有数学题作绝对正确性保证。
