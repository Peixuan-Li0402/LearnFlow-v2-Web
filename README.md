# LearnFlow v2.0.0 · 大学作业与课程学习台

本仓库仅包含网页版，不包含清小搭 Skill、平台兼容网关或个人学习数据。

## 本地启动

安装 Node.js 22.13 或更新版本，执行 `npm ci`。将 `.env.example` 复制为 `.env.local`，仅在本机填写模型服务密钥。执行 `npm run dev -- --port 3011`，打开 http://127.0.0.1:3011。

不要提交 `.env.local`、`.wrangler` 或用户上传文件。数据库和文件存放在本地 `.wrangler` 中，升级前请完整备份，不要清空该目录。

## 使用方式

“新建作业”用于独立题目；“新建课程项目”用于组织课件、知识点和课程内作业。独立作业不会自动读取其他课程。进入课程空间可使用章节树、依赖图和知识讲解；作业页保留标准答案、分步讲解、知识助手与回退。

数学解题先生成并复核蓝图，再讲解。遇到模型服务超时会保留题目并提示重试，不生成固定演示答案。可通过 `MODEL_SOLVER`、`MODEL_REVIEW` 等环境变量配置实际可用模型。

## 检查

`npm run typecheck` 检查类型，`npm test` 构建并运行回归测试。`npm start` 启动已构建的本地Worker预览。工具实验室需要单独配置 tools-service，详见其README。
